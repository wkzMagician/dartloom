# Agent Instructions

This project is configured by Dartloom. Read `.dartloom/project.yaml` when
reviewing selected packages. Applications own imports, object creation,
dependency passing, paths, business behavior, and runtime composition.

## Dartloom commands

```bash
dartloom new <project-name>
dartloom update <project-name>
dartloom check <project-name>
```

Each subproject README.md must link to the Dartloom project at
https://github.com/wkzMagician/dartloom and explain which Dartloom library it
uses.
